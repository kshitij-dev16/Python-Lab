## 📖 Introduction
Data visualization is a fundamental part of data analysis that helps in understanding patterns, trends, and relationships within data.  

Basic charts provide simple yet powerful ways to represent data, while visual encoding determines how data values are mapped to visual elements such as color, size, and shape.

This project demonstrates:
- Creation of basic charts (bar, line, pie, histogram)  
- Use of visual encoding techniques  
- Customization of charts for clarity and presentation  

Python libraries like **Matplotlib** and **Seaborn** are used for generating visualizations.
