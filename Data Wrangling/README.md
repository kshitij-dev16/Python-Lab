## 🎯 Objective
To clean, transform, and prepare raw data into a structured format using Python libraries like Pandas and NumPy for efficient analysis.

## 📂 Dataset Description
The dataset contains raw and inconsistent data which may include:
- Missing values  
- Duplicate records  
- Incorrect data types  
- Inconsistent formatting  

Example columns:
- Name / Product  
- Age / Price  
- Category  
- Quantity / Sales  

---

## ⚙️ Functions Used

- **pd.DataFrame()** → Creates structured dataset  
- **isnull() / notnull()** → Detects missing values  
- **fillna()** → Replaces missing values  
- **dropna()** → Removes missing data  
- **drop_duplicates()** → Removes duplicate rows  
- **astype()** → Converts data types  
- **rename()** → Renames columns  
- **replace()** → Replaces specific values  
- **str.strip() / str.lower() / str.upper()** → Cleans and formats text  
- **sort_values()** → Sorts dataset  
- **describe()** → Provides statistical summary  
- **info()** → Displays dataset structure  

---

## 🔄 Algorithm

1. Start  
2. Import required libraries (Pandas, NumPy)  
3. Load or create dataset  
4. Convert into DataFrame  
5. Identify missing values using `isnull()`  
6. Handle missing data using `fillna()` or `dropna()`  
7. Remove duplicate records using `drop_duplicates()`  
8. Correct data types using `astype()`  
9. Clean text using string functions (`strip`, `lower`, `upper`)  
10. Rename columns if required  
11. Replace incorrect values  
12. Sort dataset  
13. Display summary using `info()` and `describe()`  
14. Show final cleaned dataset  
15. End
