## 🎯 Aim of the Study
To process and analyze textual data using Natural Language Processing (NLP) techniques and convert unstructured text into meaningful insights using Python.

---

## 📖 Introduction
Natural Language Processing (NLP) is a branch of Artificial Intelligence that enables computers to understand, interpret, and process human language.

Text data is inherently unstructured and requires preprocessing before meaningful analysis can be performed.

This project demonstrates key NLP techniques such as:
- Tokenization  
- Stopword Removal  
- Stemming and Lemmatization  
- Text Cleaning and Normalization  
- Vectorization (TF-IDF, Count Vectorizer)  
- Feature Extraction
