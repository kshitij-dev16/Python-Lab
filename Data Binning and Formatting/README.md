## ⚙️ Functions Used

- **pd.DataFrame()** → Creates structured table from data  
- **pd.cut()** → Converts continuous data into categories (binning)  
- **astype()** → Changes data types (e.g., int → float)  
- **str.upper()** → Converts text to uppercase  
- **sort_values()** → Sorts data based on a column  
- **unique()** → Returns distinct values  
- **head()** → Displays first few rows
